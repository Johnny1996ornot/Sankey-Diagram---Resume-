Editing
• Click a card → Edit Box.
• Click a ribbon → Edit Line.
• Double-click also opens its editor.
• Drag cards to reposition them.
• Drag ↘ to resize a card.
• Ctrl-click for multi-selection.
• Connect: select source → target.
• Cut: click a connection.
• Auto ribbon width makes flows fill/split between cards.

Edit Flow Ribbon

Automatic Width makes a single flow use most of the card's available vertical space. If two or more flows leave or enter a card, that space is divided automatically between them. Turn Automatic Width off if you want to manually set the ribbon width.
